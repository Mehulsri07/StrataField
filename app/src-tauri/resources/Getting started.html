Getting started with StrataField

StrataField keeps a record of every borewell: where it is, the soil layers found at each depth, the pipes put in, water levels, photos and files. This guide takes about ten minutes to read. You can print it.

1. Installing

  1. Double-click the file StrataField_…_x64-setup.exe.
  2. If Windows shows Windows protected your PC, choose More info, then Run anyway. Windows shows this for new programs that are not yet signed. It is expected.
  3. Follow the installer. It does not need an administrator password: StrataField is installed just for you.
  4. Open StrataField from the Start menu. This guide is there too, as Getting started with StrataField.

StrataField works on Windows 10 and Windows 11.

2. The first time you open it

If this computer had the older StrataField, your borewells are brought over by themselves and a green message says how many. The older app's file is only read, never changed. You can close the message with ×.

If StrataField is new on this computer, it starts empty. Start with adding a borewell or importing an Excel file.

3. Finding your way around

The menu on the left has everything:

  • Home: the main numbers, a water-depth map of the city, recently added borewells, and anything that needs attention.
  • Borewells: the full list. Click a row to open a borewell.
  • Map: where the borewells are.
  • Cross-section: the soil layers underground along a line you draw.
  • New borewell, Import Excel, Export: adding and sharing data.
  • Recycle bin: deleted borewells, which you can bring back.
  • Settings & backup: backups, the offline map, soil types and appearance.

The line at the bottom of the window always shows that your work is Saved on this computer and when the last backup was made. All depths are in feet.

4. Adding a borewell

Choose New borewell. The steps are shown across the top; you can go back to any step.

  1. Basics: the borewell ID (suggested for you), owner and zone.
  2. Location: choose one of four ways, the first being the most accurate:
    • Use a photo's GPS: pick a phone photo taken at the borewell; its position is read from it.
    • Type coordinates: paste them, for example 26.8930, 80.9420.
    • Pick on the map: click the spot.
    • Look up the address: approximate; needs internet.
    StrataField remembers which way was used, so everyone knows how exact the location is.
  3. Drilling & water: total depth, water level, pipe size, drilling method.
  4. Layers & pipes: use Add layer for each soil layer from the top down, and Add pipe piece for the pipes. If a depth range was not recorded, StrataField points out the gap: choose Mark … ft as not recorded. Unknown depths are never filled in by guessing.
  5. Photos & files: optional; add site photos and documents.
  6. Check & save: shows anything that must be fixed first, then Save borewell.
If you close the window halfway, your unfinished borewell is kept and waiting next time.

To change a borewell later, open it and use Edit details or Edit layers & pipes. Changes to layers save by themselves. Click any layer in a drawing to see what it is and at what depth.

5. Adding borewells from Excel

  1. Choose Import Excel, then Choose Excel files. You can choose several at once.
  2. Check each file in the preview: the details found, the layers and the pipes. Fix anything marked.
  3. If a soil name is not recognised (for example "murrum"), choose which soil type it means.
  4. Choose Import. The original Excel file is kept with each borewell, under Files.

6. Finding a borewell

Press Ctrl + K anywhere, or use Find a borewell… at the top, and type an ID, owner or area. On the Borewells screen you can also filter by zone, soil type, depth, water level and date, or show only borewells with No location.

7. The map and water depths

The map shows each borewell as a dot. Colours show how deep the water is: darker means deeper. Colours between borewells are estimates, and they fade out far from any borewell. Click a dot to see that borewell.

8. Seeing the layers between borewells

  1. Choose Cross-section.
  2. Click where the line starts (A) and where it ends (A′) on the map. You can drag either end afterwards. Or try North to south or West to east.
  3. The picture shows the layers measured at each borewell near the line, and faded estimates between them. Where borewells are too far apart, it says Not enough borewells instead of guessing.

Click any layer or estimate to see where it comes from. Use Save to keep the line, or Save as picture.

9. Reports and pictures

  • On a borewell: Make PDF report for printing and sharing, or Save as picture for the drawing.
  • Export: a PDF report or an Excel workbook of all borewells, one zone, or the ones you tick.

10. Using it without internet

Everything works without internet except looking up an address. For the map to show streets offline, for example at a drilling site, download it once while connected:

Settings & backup → Map without internet → Download the Lucknow map (about 6 MB).

11. Keeping your data safe

  • StrataField makes a backup every day by itself and keeps the last 10. You can also choose Back up now on Home or in Settings.
  • Backups on the computer alone are lost if it breaks or is stolen. Set up a second copy: in Settings & backup → A second copy of your backups, choose Choose a folder… and pick a folder on a USB drive, or one that OneDrive or Google Drive keeps in the cloud. From then on every backup is copied there too. If the USB drive is not plugged in, Home tells you, and Copy now catches up.
  • To go back to an earlier state, choose Restore next to a backup. A copy of how things are now is saved first, so a restore can be undone.
  • Deleting a borewell moves it to the Recycle bin, from where it can be restored.
Your data is in the folder %APPDATA%\Strata. Settings shows it and can open it. Do not edit files there by hand.

12. Updates

When a newer StrataField is available, a message offers Install and restart. StrataField closes, updates and opens again in about a minute; your data is not touched. You can also check in Settings & backup → About → Check for updates. Nothing is installed unless you choose to.

13. Moving to another computer, or uninstalling

  • To move to a new computer: install StrataField there, then in Settings & backup choose Restore from a file… and pick a backup copied from the old computer.
  • To uninstall: Windows Settings → Apps → StrataField → Uninstall. The app is removed but your data is kept in %APPDATA%\Strata, so reinstalling brings everything back.
